# ClearFix Plumbing & Heating

Static site for ClearFix, a Bedford plumber. Built with Astro.

Public details come from the Google listing [Clear fix plumbing and heating](https://maps.app.goo.gl/oruzhUnnNiJWp1yC7), checked on 8 October 2026:

- Phone: 07345 678795
- Email on the van photo: clearfixplumber@gmail.com
- Hours: open 24 hours
- Place: Bedford. The listing does not show a street address.
- Photos: the one Google profile image, cropped on the site for layout.
- Reviews: Google shows 5.0. No written reviews were public, so none are quoted.

The canonical domain is set in `astro.config.mjs`. Change `site` before you point a real domain at the build. `robots.txt` and the sitemap use that value.

## Commands

```bash
npm install
npm run dev
npm run build
npm run audit
```

`npm run check` runs the Astro type checker.

## Search

The site includes unique titles and descriptions, canonical links, Open Graph tags, `Plumber` schema, breadcrumbs, FAQ schema where questions are visible, a sitemap, and `robots.txt`. That is the technical base. It does not guarantee a first-place ranking. Add this site’s URL to the Google listing, and ask customers to leave their own reviews on Google.
